Definition of done
===================

A backlog item can move to **Done** on the board only once all of the
following are true.

- [ ] Acceptance criteria of the item are met.
- [ ] Code is merged into `main` via a reviewed pull request.
- [ ] Tests covering the change pass in CI.
- [ ] Relevant documentation (`docs/`, `README.md`) is updated.
- [ ] No known regressions introduced.

_Adjust this checklist as the team agrees on stricter or additional criteria._
